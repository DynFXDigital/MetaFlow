# MetaFlow 0.4.8

This point release adds standards-first Agent Plugins v1 governance and makes repository-wide Copilot instruction synchronization explicitly opt-in.

## Highlights

- Set a three-state Agent Plugins v1 disposition and report repository-wide conformance and migration planning state through the engine, CLI, and extension.
- Scaffold standard-first, lossless Agent Plugins metadata while preserving legacy GitHub Copilot metadata.
- Require explicit workspace consent before synchronizing the repository-wide `.github/copilot-instructions.md` file.
- Preserve previously managed repository instruction files as retained ownership when synchronization is disabled.

## Scope

This release keeps the existing 0.4 stable lane and does not change the legacy GitHub Copilot metadata contract.
