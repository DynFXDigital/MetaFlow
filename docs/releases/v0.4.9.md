# MetaFlow 0.4.9

This point release fixes how MetaFlow displays Agent Plugins v1 packages that include client-specific extension directories.

## Highlights

- Agent Plugins v1 packages with client-extension directories such as `com.github.copilot/` now appear as one capability in the MetaFlow tree. Previously, each extension directory appeared as a separate, independently toggleable sub-tree.
- Files in those extension directories stay part of their owning package when the package is enabled or disabled.
- Packages that declare the Agent Plugins v1 schema in `plugin.json` are discovered even when they have no `README.md`.

## Upgrade notes

No action is required. Capabilities without an Agent Plugins v1 `plugin.json` are discovered the same way as before.

## Scope

This release stays on the 0.4 stable lane and does not change the legacy GitHub Copilot metadata contract.
