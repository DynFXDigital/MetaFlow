# MetaFlow 0.4.0

MetaFlow 0.4 makes it easier to package, manage, and explore the AI guidance your team shares.

## Highlights

- Package shared instructions, skills, and agents as discoverable GitHub Copilot plugins instead of managing individual file paths.
- Create and maintain capabilities with guided tools that scaffold metadata and keep plugin manifests up to date.
- Browse, filter, and enable capability folders more confidently, with direct access to the source manifests behind them.
- Start a new workspace with built-in MetaFlow authoring guidance already available.

## Improvements

- Choose how metadata is delivered globally, per repository, or per capability, including the scope for settings-backed metadata.
- Keep familiar source-relative file names when MetaFlow can do so safely.
- Work more reliably in large metadata trees, while plugin maintenance leaves unrelated Copilot configuration alone.

## Before you update

- No manual migration is required for current MetaFlow workspaces.
