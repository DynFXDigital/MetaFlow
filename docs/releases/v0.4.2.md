# MetaFlow 0.4.2

This stable point release improves built-in capability delivery and metadata authoring.

### Highlights

- First-class plugin commands, including the bundled metadata review command.
- Native VS Code contribution support for built-in MetaFlow capabilities, with a MetaFlow chat participant and independent toggles for metadata-authoring capabilities.

### Fixes

- Built-in capabilities no longer add native contribution paths to workspace settings or plugin-location configuration.
- Nested capabilities stay in their own tree locations instead of appearing beneath root instruction or other artifact nodes.
- Synchronization no longer flattens nested capability assets and removes legacy flattened files during refresh.
