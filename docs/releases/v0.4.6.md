# MetaFlow 0.4.6

This patch release makes repository-wide Copilot instruction synchronization explicitly opt-in and completes reliable workspace-settings persistence.

## Highlights

- Choose repository-wide Copilot instruction synchronization through a workspace-scoped MetaFlow setting.
- Preserve previously managed repository instructions as retained ownership when synchronization is disabled.
- Inspect migration and retention state consistently through the engine, CLI, and VS Code extension.

## Fixes

- Round-trip supported VS Code workspace settings to `.metaflow/config.jsonc`, including changes back to defaults and resource-scoped updates.
- Keep plugin metadata maintenance opt-in.
- Prevent upgrade notifications from blocking later settings refreshes in the extension host.
