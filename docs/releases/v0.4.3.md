# MetaFlow 0.4.3

This stable point release improves capability metadata authoring, discovery, and diagnostics.

### Highlights

- Capability manifests are authoritative for capability metadata, with descriptors documented in README files.
- Capability search follows metadata, including restored built-in capability search.
- Capability and plugin maintenance is more explicit and portable, with validation for plugin component directories.

### Fixed

- Capability diagnostics are scoped to active selections, preventing inactive overlaps from appearing as active warnings.

### Maintenance

- Refreshed compatible dependencies and stabilized prerelease CI and release validation.
