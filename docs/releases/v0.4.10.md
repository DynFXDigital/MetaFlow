# MetaFlow 0.4.10

This patch fixes lingering duplicate capabilities for Agent Plugins v1 packages after upgrading to MetaFlow 0.4.9.

## Highlights

- Previously cached client-extension directories no longer appear as separate capabilities after a refresh.
- Copilot extension files remain visible under their owning capability, including packages containing only Copilot rules.

## Before you update

- If a profile selected an extension directory, MetaFlow replaces that selection with the owning package. This can enable additional components in the package, including when the package was previously disabled. Profile changes follow the workspace's refresh-update policy.
- If an extension has capability-specific overrides, MetaFlow retains it and logs a warning for manual review instead of discarding the overrides.
